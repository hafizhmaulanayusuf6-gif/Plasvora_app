## Priority 3 (P3) — Long-Term Architecture & Polish

- **Decompose Monolithic Files:** Split `OrderService.php` (1,649 lines) into `OrderCheckoutService`, `OrderPaymentReconciler`, and `OrderSerializer`; split `analysis_result_screen.dart` and `create_gallery_work_screen.dart` into modular widgets; deduplicate `MaterialMatchingService::evaluateListing()` and `evaluateRequest()`.
- **Upgrade `flutter_secure_storage` (`9.2.4` -> `11.2.0`):** Eliminate discontinued transitive dependencies (`flutter_secure_storage_macos`, `js`) after reviewing v10/v11 Android keystore migration notes.
- **Image Caching & Shipping Cost Caching (`PERF-05`, `PERF-06`):** Add `cacheWidth`/`cacheHeight` or `cached_network_image` in Flutter feeds, and short-TTL (5–10 min) caching for `(origin, destination, weight)` quotes in `RajaOngkirService`.
- **Clean Up Dead Handover Code or Complete UI Wiring:** Either remove unused `lib/models/handover_item.dart` + unused repository methods or wire a dedicated Free Handover UI screen.
- **Infrastructure Validation (`NV-01`, `NV-02`):** Configure `trustProxies()` in `bootstrap/app.php` if deploying behind Nginx/Cloudflare and verify Apache/Nginx disables directory listing & PHP execution in `public/storage/`.
